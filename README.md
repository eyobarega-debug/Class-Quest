# ⚡ ClassQuest

> **A private gamified coding platform for classrooms.**

ClassQuest helps instructors manage coding challenges, monitor student activity, evaluate submissions, and turn programming practice into a competitive learning experience.

Students solve programming challenges, earn XP, level up, maintain streaks, and improve their coding rating while instructors manage the entire classroom from an admin dashboard.

---

## ✨ Why ClassQuest?

Traditional coding practice can feel repetitive.

ClassQuest adds a game-like experience to programming education:

- 🎯 Coding challenges
- ⚡ XP and leveling system
- 🏆 Competitive ratings
- 🔥 Daily streaks
- 👨‍🏫 Admin-controlled student accounts
- 🛡️ Role-based access control
- 💻 Multi-language coding
- 🧪 Automated test execution
- 👁️ Live violation monitoring
- 📊 Student progress tracking

The platform is designed for **private classrooms**, meaning students do not create public accounts themselves. The administrator creates and manages student accounts.

---

# 🚀 Features

## 👨‍💼 Admin Dashboard

Administrators have full control over the classroom.

### Student Management

- Create student accounts
- Assign usernames and passwords
- Enable / disable student accounts
- Delete student accounts
- View XP and student status
- Manage classroom users

### Challenge Management

- Create coding challenges
- Edit challenges
- Delete challenges
- Set difficulty
- Assign XP rewards
- Add supported programming languages
- Configure test cases

### Monitoring

Administrators can monitor students during coding sessions.

The monitoring system can record events such as:

- Application changes
- Window changes
- Suspicious activity
- Other configured violation events

Administrators can review violations and inspect activity for individual students.
